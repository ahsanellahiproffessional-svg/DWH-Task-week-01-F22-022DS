Task 1: The Messy Sales Log
Description: Analyzes a raw branch export file to identify data quality issues (such as duplicate orders, formatting errors, and blank categories), assigns fix ownership across source systems, ETL, and business teams, and outlines cleaning steps for accurate revenue reporting.

Task 2: OLTP vs. OLAP Systems
Description: Classifies operational and analytical workloads using the two-question test (records touched and time horizon), contrasts real-time transactional needs with historical aggregations, and explains why running heavy analytical queries on live checkouts crashes database performance.

Task 3: No History and No Single Truth
Description: Explores core data warehouse principles by analyzing how operational databases destroy history when overwriting records (breaking Inmon's time-variant property) and why disconnected departmental definitions create conflicting metrics.

Task 4: DW/BI Architecture & Kimball's Goals
Description: Maps data flows across the four architectural stages (Source Systems, ETL/Staging, Presentation, BI) using a restaurant metaphor, evaluates data governance challenges, and tests adherence to dimensional design goals.

Task 5: Regional Sales Hands-On Analysis
Description: Ingests multi-table operational files, validates 1-to-Many star-schema relationships (Products and Regions to Sales), applies historical unit-price rules, and aggregates multi-dimensional revenue metrics.
